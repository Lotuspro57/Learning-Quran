# আরবি শিখি (Arabi Shikhi)

বাংলায় আরবি পড়া শেখার অ্যাপ। সম্পূর্ণ স্ট্যাটিক (HTML/CSS/JS), কোনো বিল্ড স্টেপ বা সার্ভার লাগে না। ফোনে "Add to Home Screen" করলে অ্যাপের মতো চলে এবং অফলাইনেও খোলে (PWA)।

## ফাইল
| ফাইল | কাজ |
|---|---|
| `index.html` | পুরো অ্যাপ (ডেটা, পাঠ, কুইজ, ক্যালেন্ডার, আল-কুরআন, আপডেট বোতাম) |
| `sw.js` | সার্ভিস ওয়ার্কার: অফলাইন ক্যাশ |
| `manifest.webmanifest`, `icons/` | ফোনে ইনস্টলের তথ্য ও আইকন |
| `version.json` | সর্বশেষ সংস্করণ ও "নতুন কী আছে" তালিকা |
| `release.js` | নতুন আপডেট প্রকাশের স্ক্রিপ্ট |
| `.github/workflows/pages.yml` | GitHub Pages-এ স্বয়ংক্রিয় ডিপ্লয় |

## GitHub Pages-এ চালু করা (প্রথমবার)
1. GitHub-এ নতুন repository বানান (যেমন `arabi-shikhi`)।
2. এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডারসহ) repository-র রুটে আপলোড/পুশ করুন:
   ```
   git init && git add -A && git commit -m "v1.0.0"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/arabi-shikhi.git
   git push -u origin main
   ```
3. Repository → **Settings → Pages → Build and deployment → Source: GitHub Actions** বেছে নিন।
4. `main`-এ পুশ করলেই সাইট চালু হবে: `https://<ইউজারনেম>.github.io/arabi-shikhi/`

## নতুন আপডেট প্রকাশ (আপডেট বোতাম যেভাবে কাজ করে)
অ্যাপ চালু হওয়ার কিছুক্ষণ পর এবং প্রতি ৬ ঘণ্টা পরপর `version.json` দেখে। সংস্করণ নতুন হলে ওপরে সবুজ বার আসে: **"নতুন আপডেট এসেছে" + পরিবর্তনের তালিকা + "আপডেট করুন" বোতাম**। অগ্রগতি ট্যাবের নিচেও "অ্যাপ আপডেট" অংশে হাতে দেখার বোতাম আছে। আপডেটে ব্যবহারকারীর অগ্রগতি, তারা ও সূচি মোছে না (সেগুলো ডিভাইসের localStorage-এ থাকে)।

নতুন আপডেট দিতে:
```
# ১) index.html-এ যা বদলানোর বদলান (যেমন নতুন সূরা যোগ)
# ২) সংস্করণ বাড়ান ও বার্তা লিখুন
node release.js 1.1.0 "আল-কুরআনে আরও ৫টি সূরা" "ছোটখাটো ত্রুটি সংশোধন"
# ৩) পুশ করুন
git add -A && git commit -m "v1.1.0" && git push
```
`release.js` একসাথে `index.html`, `sw.js` ও `version.json`-এর সংস্করণ বদলে দেয়।

## স্থানীয়ভাবে চালানো
Service worker-এর জন্য `file://` নয়, সার্ভার লাগে:
```
python3 -m http.server 8000   # তারপর http://localhost:8000
```

## জেনে রাখুন
- **AI ওস্তাদ:** Claude artifact সংস্করণের AI ওস্তাদ এখানে নেই, কারণ ব্রাউজার থেকে সরাসরি AI চালাতে নিজের সার্ভার/API কী লাগে (কী ব্রাউজারে রাখা নিরাপদ নয়)। নিজের সার্ভার থাকলে `index.html`-এ `window.ARABI_CONFIG={tutorEndpoint:'https://আপনার-সার্ভার'}` দিন; সার্ভার `POST {messages:[{role,content}]}` নিয়ে `{text:"..."}` ফেরত দিলেই চলবে।
- **শব্দ:** উচ্চারণ ডিভাইসের আরবি ভয়েসে (Web Speech API) শোনানো হয়। ক্বারীর রেকর্ড করা তেলাওয়াত যুক্ত করতে চাইলে বৈধ MP3 ফাইল `audio/` ফোল্ডারে রেখে প্লেয়ার যুক্ত করতে হবে।
- **বাংলা অর্থ:** আল-কুরআন ট্যাবের বাংলা অর্থ সহজ ভাষায় লেখা ভাবানুবাদ; প্রকাশের আগে নির্ভরযোগ্য তাফসীরের সঙ্গে মিলিয়ে নিন।
- **ফন্ট:** Google Fonts থেকে লোড হয়; একবার লোড হলে অফলাইনেও কাজ করে।
